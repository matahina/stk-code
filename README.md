# SuperTuxKart Eat My Tyre (EMT) Edition.

By Nomagno, based on STK 2.X Alpha.

Rebranded by matahina with IMPORTANT FIXES!

Plus Command Manager (CM) by Kimden.

**Or in short, STK 2.Xue EMT + CM :P (too many letters)**

SuperTuxKart is a free kart racing game. The SuperTuxKart homepage can be found at <https://supertuxkart.net/>.

## Building from source

This repository is a clone from <https://github.com/Nomagno/stk-code>. However, some bugfixes since latest "release" are provided here. Follow *his* instructions but use this repo for the code.

Or you can use <https://github.com/matahina/ultimate-stk-launcher> under much development recently.
